# Danilo Rainha — pacote SEO máximo

Pacote final estático preparado para ser publicado no domínio:
https://www.danilorainha.com/

## O que foi implementado
- HTML semântico
- IDs e navegação por âncoras
- scroll suave
- menu mobile
- progressive enhancement no reveal
- fallback total caso JavaScript falhe
- suporte a prefers-reduced-motion
- WhatsApp contextual por CTA
- balão de WhatsApp em CSS/JS puro
- botão flutuante
- formulário local que prepara mensagem para WhatsApp
- FAQ nativo
- credenciais e formação sem dados profissionais inventados
- foto local sem crop
- WebP otimizado com PNG original como fallback
- logo original local
- Open Graph 1200x630
- Twitter Card
- JSON-LD Person + ProfessionalService + WebSite
- canonical
- robots.txt
- sitemap.xml
- favicon
- webmanifest
- .htaccess com headers e cache
- Política de Privacidade
- Termos de Uso
- sem Wix
- sem Smartarget
- sem Google Fonts
- sem analytics/pixels
- sem banco de dados

## SEO / publicação
Este pacote está configurado para o domínio definitivo `www.danilorainha.com`.
No staging `rf.gd`, não deixe essa versão indexável no Google. Use uma cópia com `noindex` ou bloqueio do staging.
Na publicação final, confirme que:
- https://www.danilorainha.com/robots.txt retorna o arquivo
- https://www.danilorainha.com/sitemap.xml retorna XML puro
- o site retorna HTTP 200
- HTTPS está ativo
- canonical e Open Graph apontam para o domínio final
- Google Search Console recebe o sitemap

## Dados não inventados
Danilo informou que não possui CRP; portanto nenhum CRP foi incluído.
Também não foram inventados CNPJ, valores, duração das sessões, plataforma, política de cancelamento, convênios ou associações.
